# Coffee Journal 0.3.0+3

源码与安装包见 [GitHub v0.3.0 Release](https://github.com/yuminhang666-oss/coffee/releases/tag/v0.3.0)。保留豆仓首页、离线无账号、豆袋照片、库存流水、余量校正、完整备份和撤销恢复。已有奶油浅色／浓咖深色与减少动画行为继续使用。

- 总时长输入分／秒，含滴滤；显示统一为 2分30秒、0分45秒。上限仍为 24 小时。
- 粉量、注水、购入重量、库存与校正统一一位小数；整数不显示多余 .0。注水仍为 g，粉水比只是参数比值。
- 水温在主参数区域。新记录填写实际 0–100 °C 整数，不预填；历史缺失保持“未记录”，可编辑感受而留空。
- 豆子按基本信息、产地、豆子信息、批次购入、风味感受分组。产区、庄园／农场／合作社、处理站、品种各有字段；名称不自动拼接，烘焙商不充当生产者。品种多选和自定义，处理法保留完整原文。
- 六档烘焙使用稳定 ID；浅度和极浅度优先触达。旧浅烘仍是浅度，不升级成极浅。
- 103 个分组风味词，搜索支持常见中英文别名，可直接切换六档烘焙推荐和可选产区排序（不改豆子资料和已有选择）；最近／常用来自实际记录。自定义词可编辑停用；每条最多 40 个词，每词最多 40 字符，最多 500 个自定义词。
- 豆袋标注与单杯实际风味分开；复用参数不复制感受、风味、评分、收藏、地点与额外支出，也不提前扣库存。
- 豆子详情的六项个人感官档案：0–5，0.5 步进，未填与零分开，可保存不完整档案。全部填写后才绘闭合面积；提供编号轴与对应文字值、清空和读屏描述。
- 支持同豆收藏杯参数复用、两杯历史对照、豆仓烘焙筛选和扩展搜索、手记豆子／收藏／任一已选风味筛选及清除入口。
- 烘焙天数按本地日历差计算；烘焙当天第 0 天，不预设最佳赏味期。
- 表单保护覆盖豆子、单杯、风味选择、自定义词和感官输入；失败保留输入，成功保存期间继续锁定按钮，防止重复新增及重复退出。

迁移、完整备份版本和回退约定见 [迁移说明](migration-v0.3.0.md)。实际通过的验证与限制见 [本轮验证](validation-v0.3.0.md)。来源采用范围见 [参考记录](design-and-references.md)。
