# 设计取舍与来源

本次按用户指定使用 emil-design-eng 技能。它用于约束交互反馈、时序、动效目的与细节，Flutter 侧使用原生框架实现，未移植技能中举例的网页 CSS。

主界面是豆仓；每一袋都是可以长期回看的档案。记录以冲煮之后的粉量、注水量、总时长与个人感受为核心，评分/风味放在后面，避免一开始就出现专业杯测表。没有实时冲煮流程。

颜色采用奶油白、浓咖、焦糖，原创 CustomPainter 图案与 Android vector 图标随应用打包，不依赖网络图片或字体。深色模式单独设定背景、文字和卡片层级。主页统计卡保持紧凑，把空间留给豆子列表。

卡片/导航按压缩放至 0.975，120 ms easeOutCubic；页面进入 260 ms，退出 200 ms；手记面板进入 260 ms、退出 200 ms，保留拖动关闭。频繁切换标签直接切换页面，只有选中底色做 180 ms 反馈。遵从系统减少动画：取消位移动画和按压缩放的持续过程。触控、Android 返回、键盘与字号支持保留平台习惯，不把 iOS 外观等同于真实手机性能已经达标。
